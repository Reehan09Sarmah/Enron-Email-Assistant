# Enron Mail Assistant (working title)

A learning project: an AI assistant over the Enron email corpus (about 103k emails across 150 inboxes, via the EnronQA dataset) that answers a user's questions only from mail that user may see, and is not hijacked by what an email says. What it achieves will be measured.

**Status:** checking the data; nothing built yet.

## Data note
The Enron emails are real messages from real people, released by a US regulator and widely used in research. Personal details are redacted in everything this repo shows.
